# Healium — Heart Failure Clinical Decision Support System

An AI-powered proteomics decision support dashboard that predicts heart failure
subtypes, assesses clinical risk, recommends medications, and generates a
downloadable clinical report.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Pages

1. Patient Information
2. AI Analysis
3. Clinical Report
4. Treatment Recommendation
5. Export Report
